# Pukapuka Archive

Exhibition archive of Māori book covers.

**Live site:** https://extendedwhanau.github.io/pukapuka-archive/

## For visitors and editors

- Edits save in **this browser**.
- Use **↓** for a JSON backup and **Save HTML copy** for a full portable page.
- Use **Restore** if you need an earlier browser save.
- When importing a JSON backup, choose **merge** to combine collections.

See [CONTRIBUTING.md](CONTRIBUTING.md) before publishing changes for everyone.

Open `index.html` or `Pohewa-Pahewa.html` locally if you prefer.
